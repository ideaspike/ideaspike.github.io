Last updated: October 10, 2026

Start a family

Register and confirm the parent email account, sign in, name your family and add child nickname profiles. The same signed-in device provides Parent and child modes.

Complete the reward loop

In Parent mode, create a task and choose its child and coin amount. The child submits completed work; the parent approves it before coins are earned. Children redeem available rewards with sufficient coins. The parent fulfills the reward and marks it delivered.

Voice, protection and accounts

Use the microphone to prepare tasks, rewards or supported actions, then review the visible details before confirming. Use manual forms if recognition fails or you do not want cloud AI processing. Family contains the optional Require Password for Parent setting and Delete Account. Check the affected profile before making changes. Planned banking/investment pages are not part of the current app.

Contact support

Email support@ideaspike.com with the app version, device model, operating-system version and a short description of the issue. During private testing you can also use TestFlight feedback. Do not send passwords, sign-in codes, payment details or private recordings.
